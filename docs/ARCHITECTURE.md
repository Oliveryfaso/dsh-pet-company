# 结构与交互约定

## 分工

`dsh-pet-company` 负责关怀调度、轻量设置与和宿主通信；`dsh-pet` 负责宠物窗口、视频和命中/拖拽区域。代码不调用模型，不保存用户键盘输入或健康记录。已有宠物实例ID保持稳定。

## Desktop通信

旧版宿主内本机HTTP受Desktop权限闸门限制。新桥接由宿主维护有时限的操作队列，宿主通过公开的connection.fetch注册/api/dsh-pet-company三个精确端点，真实客户端renderer经官方connection.rpc领取租约，只执行固定的state/config/broadcast/anim相对路径请求，再回传结果。不复制或设置私有权限头，不改宿主访问开关，不使用任意URL。

中继生命周期独立于设置面板；新租约立即复核状态。单租约、命令期限、响应大小限制、回执去重和关闭清理保证断线时停止、不补发已派发动作。没有可用renderer时显示暂停原因，不把客户端连接缺失误报为未安装桌宠。Web和Desktop必须分别实测。

## 配置更名

新设置在当前DSH home的`dsh-pet-company/config.json`。仅在新文件不存在时只读旧`dsh-companion/config.json`，保存写新位置。新文件损坏不回退、不覆盖；旧文件损坏时指出实际旧路径。API保留旧前缀alias，包和bundle身份使用新名称。升级时应移除旧包，避免两个调度器并行。

## 轻反馈与云朵气泡

目标视觉为220ms左右的统一缩放0.97→1.01→1，作用于专用视觉wrapper，不修改碰撞、拖拽或镜像的变换。气泡是三只宠物共用的云朵结构，仅主题色不同，默认8秒，文本写入textContent，提供不抢焦点的关闭按钮。

重复点击取消旧动画；同一次关怀的说话和动作共享eventId，严格去重。拖动开始收起气泡，释放不再按点击处理。边缘位置按DIP重新测量并上下翻转/收进视口；resize/DPR变化重算。减弱动画开启时不缩放。显示、关闭均不请求输入焦点，也不播放声音。

现版dsh-pet的原生helper气泡/点击反馈是内部固定实现，尚无主题扩展。兼容补丁将以可选per-pet presentation提供三主题、轻反馈、云朵和3–20秒时长；没有该配置的宠物维持既有行为。extra pack的外观通过按现存pet ID的安全覆盖表保存，不改写pack源文件。本轮已获用户批准，在隔离Profile中构建/安装兼容副本验证；没有自动覆盖用户的现有依赖或宿主。

## 验证边界

确定性逻辑由Node内置测试；视觉模块用真实浏览器覆盖状态与像素。真实Desktop窗口、悬浮helper、后台存活与关闭清理分别记录。多屏DIP几何测试不能冒充物理多屏实测，其他操作系统也不从Mac结果推导。

CI只检查代码、生成文件一致性和包清单，不启动宿主或下载美术工具。市场投稿与公开GitHub源码分开进行，本仓库不自动投稿。
